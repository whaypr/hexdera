## Roadmap

### ✅ Completed

- Study and update [elm-hex-grid](https://github.com/danneu/elm-hex-grid) to compile with modern Elm
- Learn the Lamdera framework and the [example chat app](https://github.com/lamdera/example-apps/tree/master/chat) in particular
- Use elm-hex-grid to build the initial game environment - isolate hex grid, add movable character and obstacles
- Integrate the game to the Lamdera's FE/BE architeture as implemented in the chat app
- Add viewpoints

### ❌ Possible Candidates For Future Updates (not an exhaustive list)

- Improve the fog of war system for gameplay use cases
- Expand tile interaction mechanics - building, destroying, ...
- Add player names and colors
- Add more gameplay features. Possible candidates are:
  - Lobbies and multiple game modes - time trial, open world, ...
  - More block types - water, lava, ...
  - Pickable and usable items
  - Player stats and item-based modifiers - health bars, buffs/debuffs, ...
  - Better UI
  - Simple in-game chat
  - NPCs - possibly with automatic pathfinding or simple AI
  - Infinite world generation
  - World export/import
  - Enhanced viewpoints
